# 自動人員配置システム

生産計画とスキルマップから、日ごとのライン人員配置案を自動生成する単体HTMLアプリです。

## 使い方

`auto-staffing.html` をブラウザで開くだけです。インストール・サーバ不要。
設定と配置結果はブラウザの localStorage に自動保存されます。

## 元データ

| 元ファイル | 取り込んだ内容 |
|---|---|
| 統合スキルマップ2026.xlsx | 様式4（43名／27項目）・様式10（22名／24項目）、実人数56名 |
| 生産計画2026.xlsx | 4〜9月の生産計画（日付×工程のロット・数量） |
| 配置表2026.08.xlsm | ポジション構成（充填／包装／調製／秤量／交代／洗浄 等） |

## 画面

- **スキルマップ更新** — セルをクリックしてレベルを 0→1→2→3→4→0 と変更。CSV出力可
- **人員設定** — ライン外優先度（1〜3）、稼働フラグ、有給・出張日
- **生産計画** — 対象月の切替と、日別に立つラインの確認
- **自動配置** — 全日分の配置案生成、CSV出力、印刷
- **ライン定義** — 各ポジションの必要スキル・必要レベル・人数

## 配置ロジック

1. 生産計画のその日の行から稼働ラインを判定（AS/MS/GS坐剤、AD・GO注入軟膏、各調製室）
2. 必要枠を「有資格者が少ない順」に処理し、希少スキルから先に確保
3. 各候補をスコアリングして最良を選択
   - **スキル充足は必須** — 必要レベル未満は候補にならず、埋まらない枠は警告
   - ライン外優先度 … 優先度×500 の減点。実質、他に人がいる限り選ばれない
   - 負荷平準化 … 累積ライン配置回数に応じて減点
   - 多能工育成 … 同一ポジションに指導可（L4）が既にいる場合、必要レベルちょうどの人を加点
   - 各ポジションに指導可を1名は入れる
4. 未配置者は洗浄・資材供給補助・間接作業へ自動振替。ライン外優先者が優先的に回る
5. 有資格者不足でライン外優先者を配置せざるを得なかった場合は日ごとに明示

## ビルド

データを差し替えるときは `data.json` を更新して再ビルドします。

```
python3 build.py   # template.html + data.json -> auto-staffing.html
```
