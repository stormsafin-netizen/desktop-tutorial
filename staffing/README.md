# 自動人員配置システム

生産計画とスキルマップから、日ごとのライン人員配置案を自動生成する単体HTMLアプリです。

## 使い方

`auto-staffing.html` をブラウザで開くだけです。インストール・サーバ不要。
設定と配置結果はブラウザの localStorage に自動保存されます。

## 元データ

| 元ファイル | 取り込んだ内容 |
|---|---|
| 統合スキルマップ2026.xlsx | 様式4（43名／27項目）・様式10（22名／24項目）、実人数56名 |
| 生産計画2026.xlsx | 4〜9月の生産計画（日付×工程のロット・数量） |
| 配置表2026.08.xlsm | ポジション構成（充填／包装／調製／秤量／交代／洗浄 等） |

## 画面

- **スキルマップ更新** — セルをクリックしてレベルを 0→1→2→3→4→0 と変更。CSV出力可
- **人員設定** — ライン外優先度（1〜3）、稼働フラグ、有給・出張日
- **生産計画** — 対象月の切替と、日別に立つラインの確認
- **自動配置** — 全日分の配置案生成、Excel／CSV出力、印刷、実績としての記録
- **配置実績** — 記録した配置の蓄積と、工程別の従事回数集計。Excel／JSON出力、JSON読み込み
- **ライン定義** — 各ポジションの必要スキル・必要レベル・人数

## 配置ロジック

1. 生産計画のその日の行から稼働ラインを判定（AS/MS/GS坐剤、AD・GO注入軟膏、各調製室）
2. 必要枠を「有資格者が少ない順」に処理し、希少スキルから先に確保
3. 各候補をスコアリングして最良を選択
   - **スキル充足は必須** — 必要レベル未満は候補にならず、埋まらない枠は警告
   - ライン外優先度 … 優先度×500 の減点。実質、他に人がいる限り選ばれない
   - 負荷平準化 … 累積ライン配置回数に応じて減点
   - 多能工育成 … 同一ポジションに指導可（L4）が既にいる場合、必要レベルちょうどの人を加点
   - 各ポジションに指導可を1名は入れる
4. 未配置者は洗浄・資材供給補助・間接作業へ自動振替。ライン外優先者が優先的に回る
5. 有資格者不足でライン外優先者を配置せざるを得なかった場合は日ごとに明示

## 配置実績

「自動配置」タブで結果を出したあと **実績として記録** を押すと、その月の配置が「配置実績」タブに蓄積されます。
記録は月単位で、同じ月を再度記録すると確認のうえ上書きされます。

蓄積されるのは日ごとの配置（氏名・ライン・ポジション・レベル）と間接作業の割り当てで、
そこから**工程別の従事回数**が集計されます。「記録上はL3だが半年間その工程に入っていない」
「実際は12回従事しているが記録はL2のまま」といったずれを見つけるための材料になります。

保存先はブラウザの localStorage です。他の人と共有する場合や端末を移る場合は、
**JSONで書き出し** で持ち出し、移動先で **JSONを読み込み** してください。読み込みは月単位のマージで、
同じ月があれば確認のうえ上書きします。

## Excel出力

「自動配置」タブの **Excel出力** で、6シート構成の `.xlsx` をダウンロードします。

| シート | 内容 |
|---|---|
| 配置案 | 日・曜日・ライン・生産ロット・ポジション・氏名・レベルの一覧（フィルタ用） |
| 日別レイアウト | 現行の配置表に近い、日ごとのブロック形式 |
| 負荷集計 | 個人別のライン配置回数・ライン外優先度・有給日数 |
| 警告 | 有資格者が足りず埋まらなかった枠 |
| スキルマップ様式4 / 様式10 | 更新後のスキルマップ（レベル別に色分け） |

「スキルマップ更新」タブの **Excel出力** はスキルマップ2シートのみ、
「配置実績」タブの **Excel出力** は実績明細と工程別従事回数の2シートを出力します。

見出しの固定、列幅、レベル別の色分け（L4/L3/L2/L1）、不足箇所の赤塗りが付いた状態で出力されます。
生成は外部ライブラリなしの内蔵XLSXライター（無圧縮ZIP + OOXML）で行うため、オフラインでも動作します。

## ビルド

データを差し替えるときは `data.json` を更新して再ビルドします。

```
python3 build.py   # template.html + data.json -> auto-staffing.html
```
