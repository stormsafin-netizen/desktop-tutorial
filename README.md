## Installation

Follow these steps to get started with this project on your local machine.

### Prerequisites

- [Git](https://git-scm.com/downloads) installed on your system
- [GitHub Desktop](https://desktop.github.com/) (optional, recommended for beginners)

### Steps

1. **Clone the repository**

   Using Git:
   ```bash
   git clone https://github.com/stormsafin-netizen/desktop-tutorial.git
   ```

   Or click the **Code** button on GitHub and select **Open with GitHub Desktop**.

2. **Navigate into the project directory**

   ```bash
   cd desktop-tutorial
   ```

3. **You're all set!**

   Open the project in your preferred editor and start exploring.
